## O que você encontra

- Apresentação e áreas de foco em desenvolvimento e informática.
- Tecnologias: HTML, CSS, JavaScript e estudos em C#.
- Projetos em destaque: [SCAIA](https://github.com/Birogiro/SCAIA_controle_de_atividades) e [Sevastopol Archives](https://github.com/Birogiro/sevastopol-archives).
- Interface responsiva, navegação por seções e animações de entrada.

## Executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/Birogiro/portfolio.git
   ```

2. Abra a pasta `portfolio` e o arquivo `index.html` no navegador.

Não há etapa de compilação nem dependências de instalação.

## Estrutura

| Arquivo | Responsabilidade |
